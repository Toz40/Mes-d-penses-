# Mes Dépenses - PWA iPhone

Application web installable (PWA) de gestion de dépenses partagées avec retraits d'espèces ventilables.

## Fonctions
- Plusieurs groupes / voyages
- Participants
- Dépenses partagées
- Répartition égale ou personnalisée
- Retraits d'espèces avec sous-dépenses
- Contrôle du cash restant
- Catégories
- Devises : EUR, MAD, USD, GBP, CHF, CAD
- Photos de tickets (compressées localement)
- Soldes et remboursements suggérés
- Sauvegarde locale sur l'appareil
- Export / import JSON
- Fonctionnement hors connexion après première ouverture

## Installation sur iPhone
Une PWA doit être publiée sur une adresse HTTPS. Une fois le dossier hébergé :
1. Ouvrir l'adresse dans Safari.
2. Toucher le bouton Partager.
3. Choisir « Sur l'écran d'accueil ».
4. Valider avec « Ajouter ».

## Hébergement
Le dossier est 100 % statique. Il peut être publié gratuitement sur GitHub Pages, Netlify, Cloudflare Pages, Vercel ou tout hébergement HTTPS.

Important : les données sont stockées localement dans Safari sur cet appareil. Utiliser régulièrement Exporter dans Réglages pour conserver une sauvegarde.
